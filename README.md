# emjixd-hub

Personal link-in-bio and hub for [emjixd.my.id](https://emjixd.my.id).

Built with pure HTML and CSS. No frameworks, no build steps, no bloat. Just a single index file to hold my socials.

## Deployment

1. Drop `index.html` and the profile image on any static host (GitHub Pages, Vercel, Netlify).
2. Point the custom domain.
3. Done.
